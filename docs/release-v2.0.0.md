# World Trends v2.0.0

## 사용자 기능
- 전세계 기본 화면과 국가별 화제 개수 설정, 즐겨찾기 및 언어별 국가 정렬.
- 회전 가능한 지구본, 국가 선택, 낮밤 및 시계 표시 토글.
- 관련 기사 썸네일, 저장한 화제, 접을 수 있는 국가 목록.
- 한국어·일본어·영어 UI와 상세 모달의 원문·번역 병기. 카드 자동 번역은 요청 지연을 줄이기 위해 사용하지 않습니다.
- Google Trends 지원 국가 외에는 GDELT의 발행 국가별 뉴스를 구분하여 제공합니다.
- 제공자 오류·빈 응답 시 기존 캐시 보존과 재시도 제한.

## 운영
- dev → stg → prd PR 승격 및 각 브랜치 CI 검사.
- 환경별 실행 경로·데이터 분리와 포털 등록. 기존 운영 URL과 저장 데이터 유지.
- 기존 Tailscale 기기 제한·공통 로그인·Origin/CSRF 보호 재사용.

## 알려진 제약
- 검색 트렌드와 뉴스 화제는 서로 다른 지표이며 국가·제공자별 정보량과 갱신 시점이 다릅니다.
- 외부 뉴스·썸네일·무료 번역은 제공자 상태와 요청 한도에 영향을 받습니다.
- PR 머지 후 로컬 환경 갱신 및 재시작은 별도 배포 단계입니다.
